# W-168. Validate work amplification with purpose-built adversarial fixtures

## Problem

W-167 measures benign fixtures and analyzes the amplification paths in the code, but W-149's decision requires measured evidence on documents built to exercise those paths: repeated object-stream decoding, stacked filters, long cross-reference chains, and long-running steps without a cancellation checkpoint.

## Scope and exclusions

Produce purpose-built adversarial fixtures for each amplification path that `agents/reference/w-149-work-budgets.md` lists as unmeasured, run them through the W-167 counters and the same public operations, and add the observed counts and cancellation latencies to that report. Do not implement a limit, a cache, or a change to the D-49 release policy.

## Acceptance criteria

- Each path the report lists as analysis only has a fixture, a command, and observed counts for source I/O, decoded bytes including intermediate stages, traversal, retained memory, and cancellation latency.
- The report states which paths are material at production-sized inputs.

## Evidence required

The report's recorded commands and observed counts over the adversarial fixtures.

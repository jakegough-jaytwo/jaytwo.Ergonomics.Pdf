## Problem

The R3 exit criteria concern the operations together: complete remapped object graphs, independent-tool inspection and rendering, deterministic conflict rules, and working-set memory (`reset-plan.md` section 9).

## Scope and exclusions

Run the A15 fixture set, a 100,000-page input and a multi-gigabyte stream for memory, the Docker gate, and the independent-tool sweep. Excluded: new behavior.

- Every A1 to A15 row is Exists with a test or a recorded reason.

- Memory follows the working set on the large inputs.
- `make docker-builder docker-test` passes.

## Evidence required

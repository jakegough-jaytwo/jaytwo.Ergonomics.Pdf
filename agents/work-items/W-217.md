# W-217. Apply the owner-selected encryption tolerance policy

## Problem

W-155 measured long O/U/OE/UE acceptance (with long U failing owner authentication), CF Length acceptance in bit units, and unencrypted direct trailer Info acceptance. The closed writer-quirk list has no evidence adopting these forms. Synthetic mutations and tolerant independent readers do not establish a real producer need. R4 version-specific defaults and deprecated R5 behavior must remain distinct from malformed input.

## Scope and exclusions

Resolve proposed D-67 with the owner first, then replace this research-only allowed_changes with exact implementation/test/contract paths for the approved slice. Default proposal: exact security-value sizes, indirect Info, byte-unit CF lengths; preserve PDF1.7 optional CF Length and do not change R4 top-level defaults or add smaller V4 RC4 keys without independent fixtures and version-specific reasoning. Any retained tolerance needs a real-world producer fixture, permanent test and owner-approved quirk wording. Do not opportunistically add raw UTF-8 retries or encrypted object-zero conventions. No implementation or protected edits are authorized by this proposed record.

## Acceptance criteria

- Owner-approved exact policy and wording precede affected implementation; confirm version-specific R4/CF rules rather than mechanically applying PDF2 requirements to PDF1.7.
- Every confirmed change has permanent positive/refusal regressions, user/owner checks for O/U sizes, and failure guarantees matching the adopted contract.
- Unsupported valid variants, including smaller V4 RC4 keys if independently demonstrated, receive explicit narrow implementation or documentation disposition, not an undocumented tolerance.
- All relevant shipped-contract/quirk records change in the same implementation transaction; no synthetic file is labeled a real-world producer fixture.

## Evidence required

W-155 findings, manifest and public-API/independent-tool outputs form the starting evidence. After approval, choose focused tests for each approved change; affected runtime families only where encoding/crypto differs. No broad matrix or Docker checkpoint by default.

## Closeout

Not started; owner decision required before rescoping and activation.

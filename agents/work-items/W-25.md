# W-25. Failure diagnostics omit secrets

## Problem

`QUALIFICATION.md` gate G9 requires that failure handling does not expose passwords, PINs, or key material through diagnostics. No test showed that.

## Why now

G9 is release-blocking, and this check was missing.

## Scope and exclusions

Tests only, in `EncryptionTests.cs` and `SignatureTests.cs`. No `src/` change unless a check fails, and then stop with a defect report. Do not pass G9. Do not log a password, a PIN, or key material in the test output. Does not reopen W-19.

Re-scoped once: no library API receives a PIN, so this item asserts no PIN omission. The password and key-material criteria are unchanged. G9's PIN line stays open.

## Acceptance criteria

A failing operation's diagnostic text does not contain a password or key material. The test output does not print those values. G9 is not passed. `QUALIFICATION.md` section 11.

## Evidence required

Internally tested.

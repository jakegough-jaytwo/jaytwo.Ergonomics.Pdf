# W-176. Register the W-163 link fixtures as a focused fixture set

## Problem

1. **Summary.** W-163 added four SafeDocs PDFs in `Fixtures/assembly-links/`, which D-59 forbids.
2. **Impact.** Jenkins build 14 on `wip` failed `CorpusManifestTests.every_fixture_pdf_has_a_manifest_entry` on net10.0, net8.0, and net6.0.
3. **Reproduction.** `dotnet test test/jaytwo.Pdf.Tests -f net10.0 --filter FullyQualifiedName~CorpusManifestTests`.
4. **Expected.** Every fixture PDF belongs to a recognized class.
5. **Actual.** Four "a fixture PDF is in Fixtures, Fixtures/corpus, or Fixtures/defects" problems.
6. **Severity.** Medium: the CI gate fails; no product behavior is wrong.

## Scope and exclusions

Implements D-63: move the set to `Fixtures/focused-assembly-links/`, register it in `FocusedFixtures.Sets`, rewrite its `fixtures.json` to D-63 rule 2, let `CorpusManifestTests` accept registered sets, and add `FocusedFixtureTests` for rules 1 to 3. No fixture bytes, G2 corpus entry, or assertion in `AssemblyLinksTests` changes.

## Acceptance criteria

- `CorpusManifestTests`, `DefectFixtureTests`, `FocusedFixtureTests`, and `AssemblyLinksTests` pass.
- An unregistered `focused-*` directory, an unmanifested PDF, a hash mismatch, or a missing attribution file fails `FocusedFixtureTests`.

## Evidence required

Those four test classes on net10.0, and a temporary unregistered PDF to see the check fail.

## Closeout

Moved the set to `Fixtures/focused-assembly-links/` with its bytes unchanged, registered it in `FocusedFixtures.Sets`, and rewrote `fixtures.json` to D-63 rule 2. qpdf, which `AssemblyLinksTests` already runs, is now a validator, and the test itself is listed as a consuming test. `CorpusManifestTests` accepts registered sets and rejects a corpus entry inside one. `FocusedFixtureTests` checks D-63 rules 1 to 3. `dotnet test test/jaytwo.Pdf.Tests -f net10.0` over `CorpusManifestTests`, `DefectFixtureTests`, `FocusedFixtureTests`, and `AssemblyLinksTests` passed 39 of 39. Then, in the net10.0 output, I added an unregistered `focused-rogue/x.pdf` and an unmanifested `extra.pdf`, appended a byte to one fixture, and removed `LICENSE`. The run reported each of the four faults, and the output was then restored. Completed 2026-10-25.

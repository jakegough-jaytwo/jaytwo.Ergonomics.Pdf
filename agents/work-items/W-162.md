# W-162. Extract pages (N1)

## Problem

Extracting selected pages into a new file is the first Phase 2 operation (spec N1, A1 to A5).

## Scope and exclusions

Add the engine's public extraction entry point over input occurrences. Resolve inherited page properties, clone page-owned annotations per output page, and omit outlines, tagging, page labels, XMP, attachments, signatures, and catalog actions. Refuse a nonempty `/AF` (within the A5 scope), `/OCProperties`, and dynamic XFA before output. Excluded: links, appearances, form namespacing, encrypted input, and concatenation of several occurrences.

## Acceptance criteria

- A1: a page number above the page count is rejected before output. `3, 3, 7` writes three distinct pages.
- A2: repeated source pages have distinct page and annotation objects and share fonts and images.
- A3 and A4: the output has no signature field, outline, tag tree, page label, XMP, or document attachment, and has a new `/ID` and a minimal `/Info`.
- A5: each refusal throws a typed error before the first byte, including `/MCAF` and an annotation `/AF`.
- Page selection, order, and resources survive qpdf, Poppler, and MuPDF rendering.

## Evidence required

Focused tests on net10.0, `make quiet-build`, and one qpdf and Poppler inspection of the built outputs.

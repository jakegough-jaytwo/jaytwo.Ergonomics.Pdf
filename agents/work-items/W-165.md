# W-165. PdfWorkflow.Combine

## Problem

Reset stage R3 asks for a simple stapling workflow over the engine's assembly API (`reset-plan.md` section 9).

## Scope and exclusions

Add `PdfWorkflow.Combine` with page ranges, the link option, the encrypted-input option, and the F-row output rules for streams and files. A compose builder is added only if a use case shows `Combine` is not enough. Excluded: any PDF logic in the workflow.

## Acceptance criteria

- The workflow describes inputs and ranges without reading them, runs once, borrows caller streams, and rejects bad page numbers before output.
- Output to a path follows F17. Engine exceptions propagate unchanged.
- Output equals the engine's assembly of the same selections.
- The workflow uses only the public API of both libraries.

## Evidence required

Focused `jaytwo.Ergonomics.Pdf.Tests` on net10.0 and `make quiet-build`.

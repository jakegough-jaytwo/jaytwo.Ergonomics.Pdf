# W-62. Align the charter documents with the Phase 1 spec

## Problem

`AGENTS.md`, `README.md`, `QUALIFICATION.md`, and the source-of-truth section of `pdf-task-workflow` still describe the pre-D-38 scope. They exclude rotate, merge, split, and ECDSA, read only PDF 1.0 to 1.7 without the agreed associated-file rule, name one runtime package, and set release gates sized for the old scope. Under the current "sources disagree, stop" rule, every Phase 1 feature item would stall.

## Why now

This is item 1 of the agreed reset plan (`agents/reference/charter-reset-plan.md`, C2). Every Phase 1 feature item depends on it.

## Scope and exclusions

Plan steps A1, A2, A3, and A5:

1. Draft the exact text as full proposed files: `agents/reference/drafts/AGENTS.proposed.md`, `agents/reference/drafts/QUALIFICATION.proposed.md`, and `agents/reference/drafts/pdf-task-workflow.sources.proposed.md` (the replacement source-of-truth section only). Drafts are not named `AGENTS.md`, because some agent tools load any `AGENTS.md` as live instructions.
2. Reach consensus on the drafts with an independent reviewer in `agents/reports/2026-10-19-W-62-review.md`.
3. Obtain the owner's approval of the exact text.
4. Apply the approved text, update `README.md` per A3, regenerate the qualification status and acceptance matrix against the new gates per A5, and delete the drafts.

Excluded:
- the target-framework switch (A4, item 2);
- workflow slimming, including the B3 task-check change and the B4 skill shortening (item 3). `AGENTS.md` keeps describing today's task-check until item 3 changes it.
- any source or test change.

## Acceptance criteria

- The applied `AGENTS.md`, `QUALIFICATION.md`, and skill section match the owner-approved text exactly.
- Nothing in `AGENTS.md`, `README.md`, `QUALIFICATION.md`, or `pdf-task-workflow` contradicts `docs/spec/phase-1.md` under the A1 rule.
- `README.md` labels Phase 1 as the 1.0 target and keeps shipped behavior separately visible.
- `make agents-check` and `make task-check` pass.

## Evidence required

Independent review consensus and owner approval of the exact text. Documentation only.

# W-163. Links, destinations, and appearances for assembled pages

## Problem

Extracted pages lose all navigation unless links are rebuilt from the whitelist (spec A6 to A10, A14).

## Scope and exclusions

Rebuild internal links and destinations, resolve named destinations, keep `http`, `https`, and `mailto` links, resolve relative URIs against `/URI /Base`, copy supported `/AP` under limits, and return the omission result. Add the two-state link option. Excluded: remote or launch actions, action chains, and form widgets.

## Acceptance criteria

- A6: the first-occurrence and own-copy rules hold, and a link to an uncopied page is dropped.
- A7 and A8: `/Next`, `/IsMap true`, `/AA`, userinfo, an unsupported scheme, and an unresolvable relative URI each drop the whole link; the PDF Association fixtures behave as the spec lists.
- A9: a local `/AP` limit omits the annotation, a global limit aborts, and no object of an omitted annotation is emitted.
- A10: the result holds counts by reason code and its size does not grow with annotations.
- A14: `Drop` removes every external link.

## Evidence required

Focused tests on net10.0 and `make quiet-build`.

# W-85. Let a shipping item mark its spec requirement Exists

## Problem

`AGENTS.md` requires the implementing item to mark a New or Change requirement Exists, but also requires owner approval for any `docs/spec/` edit, so each shipped requirement needed a separate approval (W-66, W-84).

## Why now

The owner asked on 2026-10-20 to stop approving status edits one at a time.

## Scope and exclusions

- `AGENTS.md` gains an exception to the owner-approval rule for the status edit; D-43 records it.
- Excluded: requirement text, adding, removing, or moving requirements, `QUALIFICATION.md`, and the skills.

## Acceptance criteria

- `AGENTS.md` lets the shipping item set a requirement's status to Exists without separate approval. No `ACCEPTANCE.md` row changes.

## Evidence required

`make agents-check` and `make task-check`.

## Notes

- 2026-10-20: Created at the owner's request. The owner wrote the `AGENTS.md` paragraph.

## Closeout

Done 2026-10-20. `AGENTS.md` carries the D-43 exception. `make agents-check` and `make task-check` passed.

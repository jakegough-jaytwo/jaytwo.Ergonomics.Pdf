# W-27. Review the signer from outside its implementer

## Problem

No one other than its implementer had reviewed the signer for hostile input. Gate G8 asks for an independent review of the parser and the signer.

## Why now

G8 is release-blocking, and a code review was possible before the fuzz run.

## Scope and exclusions

The AcroForm Engineer reviews the signer, read-only. No `src/` and no tests. Report confirmed defects, or state that none were confirmed, with the files read. This is not the fuzz run and does not replace W-18. Do not pass G8.

## Acceptance criteria

A report lists confirmed defects, or states that none were confirmed, and names the files read.

## Evidence required

Not stated in the original entry. A code review, confirmed by the Technical Lead.

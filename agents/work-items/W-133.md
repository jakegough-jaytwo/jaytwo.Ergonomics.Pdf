# W-133. Stabilize the semantic jaytwo.Pdf public API

## Problem

Reset stage R1 step 5 (`reset-plan.md` section 7). After the move, editor split, and source change, the engine's public surface needs a pass against D-54: semantic page, geometry, field, widget, attachment, metadata, revision, permission, and signature models; no raw object model; lazy inspection.

## Scope and exclusions

Review the public surface of `jaytwo.Pdf`. Make any raw dictionary, token, or indirect object that is public internal, and make eager inspection lazy where practical. Keep password permissions, DocMDP and FieldMDP restrictions, and cryptographic enforcement as separate results (`reset-plan.md` migration rule 11). Record the surface in Closeout.

No new capability and no algorithm rewrite.

## Acceptance criteria

- No public type exposes the raw object model.
- Inspection keeps its sparse working-set tests green.

## Evidence required

Focused tests for any changed member and `make quiet-test LANE=fast`.

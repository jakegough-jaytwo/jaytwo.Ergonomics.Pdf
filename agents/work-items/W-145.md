# W-145. Workflow read shortcuts the R2 decision adopts

## Problem

`reset-plan.md` section 8 allows read shortcuts "only where they reduce real ceremony", such as exporting form values without managing a document's lifetime. W-141 decides which ones qualify.

## Scope and exclusions

Implement only the read shortcuts that W-141's decision adopts, each with the ownership and cancellation rules of W-142's entry points. If the decision adopts none, cancel this item.

Excluded: a shortcut that only renames an engine property, and any inspection the engine does not already provide.

## Acceptance criteria

Refine these criteria from W-141's decision at activation.

- Each shortcut returns the same result as the direct-engine call and reads no more source bytes.
- Each shortcut honors input ownership and cancellation as W-142's entry points do.

## Evidence required

Focused `jaytwo.Ergonomics.Pdf.Tests` on net10.0 and `make quiet-build`.

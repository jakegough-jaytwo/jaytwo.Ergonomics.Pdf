# W-144. Attachment and page-rotation workflow operations

## Problem

Stage R2 includes adding and removing attachments and rotating pages (spec W6, W8 to W13). As workflow operations, attachment content becomes a deferred input with its own ownership, which the engine's `Add(name, Stream, leaveOpen)` does not cover for a description recorded before the run.

## Scope and exclusions

Implement spec F8, F9, and F10 for rotation (section 6.7, D-60): `Attach`, `AttachFile`, `RemoveAttachment`, `RotatePage`, `RotatePageBy`, and `RotateAllPagesBy`. Each replays on the editor in declaration order with engine semantics (F5).

Excluded: any change to engine attachment or rotation behavior, and page-level file attachment annotations (never in scope).

## Acceptance criteria

- F8: `Attach` checks that the stream is readable and seekable and records its position, reading nothing (F1). The run seeks to that position, and a stream shorter than the recorded position is rejected before output. `AttachFile` opens the file during the run, once for both of the engine's reads, and closes it on success and failure. MIME: a caller-supplied type wins; `.XML`, `.Json`, `.pdf`, `.csv`, and `.txt` map case-insensitively from the table; any other extension leaves it unspecified.
- F5 and F8: add then remove, remove then add, and add twice under one name each give the result of the same engine calls in order. Removing a missing name throws `PdfAttachmentNotFoundException` before output.
- F9: `RotatePageBy` twice accumulates, `RotatePage` after `RotatePageBy` sets the absolute value, and `RotateAllPagesBy(90)` adds 90 to each page's own rotation. A page number below 1 or an angle that is not a multiple of 90 is rejected when described. A page number above the page count is rejected before output.
- F4: attachment and rotation workflows each append one revision, keep the input as an exact prefix, and inspect the same as the direct-engine sequence. Rotation bytes are identical. Attachment dates come from the clock, so those outputs are compared by inspection.
- F10: rotation on a document with an approval signature requires `AllowBreakingExistingSignatures()`.
- The XML docs on `Attach` state that the content must not change before or during the run. A change before the run cannot be detected (D-60); the engine detects one during it.

## Evidence required

Focused `jaytwo.Ergonomics.Pdf.Tests` on net10.0 and `make quiet-build`.

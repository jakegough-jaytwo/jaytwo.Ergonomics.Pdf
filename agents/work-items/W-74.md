# W-74. Raise the catalog version up to 1.7

## Problem

A write that uses a feature newer than the file's effective version does not raise the catalog `/Version` (spec §7.5).

## Why now

Reset plan C2 item 15. `/PageMode /UseAttachments` (W-75) needs it.

## Scope and exclusions

- Raise catalog `/Version` up to `/1.7` when a written feature needs it; never to `/2.0`; never rewrite the header.
- `/AF` and `/AFRelationship` never trigger a raise.

## Acceptance criteria

- Effective versions are correct for 1.4, 1.5, 1.6, and 1.7 inputs.
- A PDF/A-3 input stays at 1.7.

Refine these criteria, and the `ACCEPTANCE.md` rows they add or change, when the item becomes active. A write item also meets every check in plan C4.

## Evidence required

Independent reader of the effective version.

# W-38. Signing input bounds and diagnostics (audit SA-05, SA-06)

## Problem

- SA-05 (High): certificate, chain, signature, and timestamp callback bytes are copied repeatedly before the `ReservedContentsBytes` check, and `AdditionalCertificates` enumeration is unbounded.
- SA-06 (High): exceptions from the host's `CertificateDer` and `AdditionalCertificates` escape without sanitizing. Only `SignHash` is inside the sanitizing catch. This is a real G9 diagnostic path, although the public API never receives a PIN.

## Why now

Both are release blockers.

## Scope and exclusions

Bound the work before the size check. Sanitize exceptions from both certificate properties the way `SignHash` exceptions are sanitized. SA-06 needs regression cases for failures from both properties, not only `SignHash`.

## Acceptance criteria

Bounded work before the size check. Exceptions from both certificate properties are sanitized like `SignHash` exceptions, and the destination is unchanged.

## Evidence required

Internally tested.

- Two existing tests changed because the size check now runs before the parse: `RejectTimestamp` reserves 8,192 bytes instead of 1,024, and the undersized certificate-bearing timestamp test reserves leaf + 256 + 64.

## Closeout

Accepted at the internally tested level. Closes SA-05 and SA-06. The CMS provider reads `CertificateDer` once and enumerates `AdditionalCertificates` once, before `SignHash`. Every host access is sanitized to a generic `CryptographicException`. The leaf, chain, signature value, and token are checked against `ReservedContentsBytes` before any DER is built or parsed, so an endless chain stops at the first certificate past it. The document-timestamp token is checked the same way. Thirteen regression tests; the destination is unchanged on every failure path. `IPdfExternalSigner` XML docs, the `README.md` failed-sign bullet, and the `ACCEPTANCE.md` external-signer bullet describe the behavior, and one bound bullet was added. Limitations: an early stop reports a lower-bound `ActualBytes`. `ITimestampAuthority` exceptions pass through unsanitized, a QA observation that became W-49. Reports: `agents/reports/2026-10-19-signing-engineer-B-38.md`, `2026-10-19-qa-engineer-B-38.md`, and `2026-10-19-tech-lead-B-38-review.md`. Completed 2026-10-19.

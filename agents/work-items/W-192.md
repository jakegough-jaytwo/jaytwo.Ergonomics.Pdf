# W-192. Specify navigation and URI semantics for assembly

## Problem

Current omission and URI policy choices require explicit supported semantics and a distinction between unselected targets and broken references.

Source: [simplification charter](../reference/reset-siimplify.md), PLAN 07 / O 11. Ticketing baseline: `82a83855581115400d4ecb5f6884895c20ecb45b`; reverify observations at execution. This records a research question, not a verified defect.

## Scope and exclusions

Inventory GoTo, URI, relative bases, IsMap, Named, GoToR, /Next, /AA and catalog-open behavior. Recommend removing scheme/userinfo sanitization only as an approved assembly responsibility change, retaining structural validation and a typed action subset.

Research and draft proposals only. Exclude runtime/test-suite changes, protected-file edits, shipped-contract changes, active-queue changes and implementation. Store findings, exact wording proposals and bounded disposable probe material under `agents/reference/simplification/W-192/`. Follow-up implementation gets its own owner-approved item and allowed paths.

## Acceptance criteria

- Retain the self-link-to-own-copy and other-link-to-first-selected-copy rule within each input occurrence unless exact superseding wording is approved.
- Separate deliberate target exclusion, malformed references and unsupported meaningful actions; never replace an unsupported action with a misleading inert artifact.
- Require an explicit usable source base for relative URIs; never infer a filesystem base.
- Provide exact supported/refusal wording, observed baseline, compatibility cost and bounded implementation slices.

## Evidence required

Small destination/action probes covering repeated inputs/pages, relative URIs and malformed targets, inspected with an independent reader. Copied actions are never executed by the probes.

Record measured versus inferred claims and missing tools/coverage explicitly. Run `make agents-check` and staged `make task-check` for planning records. No full framework matrix, fuzz campaign or Docker gate is required for this research item.

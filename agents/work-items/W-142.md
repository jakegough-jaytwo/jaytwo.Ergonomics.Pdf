# W-142. Workflow pipeline with deferred operations, one editor session, and metadata

## Problem

`jaytwo.Ergonomics.Pdf` contains no source. Stage R2 needs the pipeline that every workflow operation uses: `PdfWorkflow.From`, deferred descriptions, validation before output, one `PdfDocumentEditor` session, the stream and file outputs, and task-level errors. Metadata is the first operation, so the pipeline ships observable behavior and the later operation items only add operations.

## Scope and exclusions

Implement the entry points, output, validation phases, exception model, and sync/async surface that W-141's decision chooses, plus the metadata operation. Update the project `Description`, which still describes the pre-reset single library. Set the requirements this item implements to Exists, and update `README.md` and `ACCEPTANCE.md` in the same commit (D-43).

Excluded: forms (W-143), attachments and rotation (W-144), read shortcuts (W-145), and signing (stage R4). Ergonomics contains no parsing, serialization, or object manipulation; it calls only public `jaytwo.Pdf` APIs.

## Acceptance criteria

Refine these criteria from W-141's decision at activation.

- `From` and operation descriptions perform no source reads, as counted by a test `IPdfSource`.
- A metadata workflow appends exactly one revision whose bytes equal the direct-engine equivalent, and it reads no more source bytes than that equivalent.
- Borrowed inputs and destinations stay open, and owned ones are disposed, as the decision specifies, on both success and failure.
- An invalid workflow fails before the destination is written: a stream destination keeps its length, and a file destination is not created or replaced.
- Cancellation observed during a run leaves a seekable destination at its original length and publishes no file.
- An engine failure surfaces with its failure category visible, as the decision specifies.

## Evidence required

Focused `jaytwo.Ergonomics.Pdf.Tests` on net10.0 and `make quiet-build`. Add the netstandard2.0 lane if file-replace or async disposal differs there.

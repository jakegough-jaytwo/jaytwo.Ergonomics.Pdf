# W-177. Share one fixture list between the jaytwo.Pdf test projects

## Problem

1. **Summary.** `jaytwo.Pdf.NetStandard.Tests` (D-51) compiles the `jaytwo.Pdf.Tests` sources but kept its own copy of the fixture `Content` items. W-176 added `Fixtures\focused-*\*` to `jaytwo.Pdf.Tests` only.
2. **Impact.** Jenkins build 15 on `wip` failed: the three `FocusedFixtureTests` failed in `jaytwo.Pdf.NetStandard.Tests` on net8.0, because `Fixtures/focused-assembly-links/fixtures.json` was not in its output. The same tests passed in `jaytwo.Pdf.Tests` on net10.0, net8.0, and net6.0.
3. **Reproduction.** `dotnet test test/jaytwo.Pdf.NetStandard.Tests --filter FullyQualifiedName~FocusedFixtureTests` at 0370d4c.
4. **Expected.** Both projects copy the same fixtures.
5. **Actual.** `DirectoryNotFoundException` and "focused-assembly-links: registered, but missing".
6. **Severity.** Medium: the CI gate fails; no product behavior is wrong.

## Scope and exclusions

Move the fixture `Content` items into `test/jaytwo.Pdf.Tests/Fixtures.targets`, which both projects import. Neither project lists fixture items of its own, so a fixture directory added to the shared file reaches every lane. No fixture and no test changes.

## Acceptance criteria

- `jaytwo.Pdf.Tests` copies the same fixture files as before the change.
- `jaytwo.Pdf.NetStandard.Tests` copies the same fixture files as `jaytwo.Pdf.Tests`.
- `FocusedFixtureTests`, `CorpusManifestTests`, `DefectFixtureTests`, and `AssemblyLinksTests` pass in both projects.

## Evidence required

Compare the output `Fixtures/` file lists from a clean build, and run those four classes in both projects.

## Closeout

Added `Fixtures.targets` with the five fixture item groups, linked by path so they apply to both projects, and replaced each project's list with an import. After clearing both output `Fixtures/` trees and rebuilding, `jaytwo.Pdf.Tests` net10.0 listed the same 76 files as before, and `jaytwo.Pdf.NetStandard.Tests` net8.0 listed the identical 76, which now include the focused set. Both builds had 0 warnings and 0 errors. The four classes passed 39 of 39 in each project. Completed 2026-10-25.

# W-230. Cover the remaining WORKFLOW-BEGIN-01 cases for Timestamp, writable append and concurrent path terminals

## Problem

W-228 and W-229 left WORKFLOW-BEGIN-01 untested for the `Timestamp` terminals, for a successful `AppendToSource` as a begin case, and for concurrent path and Combine calls.

## Scope and exclusions

Tests and the acceptance row only; fix the product only if a test exposes a gap consistent with the adopted contract. Keep W-228's post-claim missing-directory, existing-file and read-only-append handling and W-229's non-seekable Combine support. Out: the adopted contract, release qualification, a real timestamp authority run.

## Acceptance criteria

- `Timestamp` and `TimestampAsync` (stream and path): invalid arguments leave the description usable; refusal, pre-cancelled token and failure after accepted arguments consume it once.
- A successful `AppendToSource` on a writable stream and file consumes it once.
- Concurrent `Save(path)`, Combine and `Timestamp` calls execute exactly one valid call.

## Evidence required

The new tests on net10.0 and net48; full Ergonomics net10.0 suite; build; `make agents-check`, `make task-check`.

## Closeout

2026-11-01: no gap found; every new test passed on the first run against the unchanged product code, so there is no product change. Tests added: `rejected_timestamp_arguments_do_not_consume_the_description` (12 cases: null, read-only, non-seekable, non-empty and position-5 streams, null, empty and illegal paths, null authority, sync and async; a corrected call reaches the failing authority exactly once and consumes the description), the timestamp refusal, pre-cancelled (accepted and rejected argument) and concurrent cases, `a_successful_append_on_a_writable_source_consumes_the_description_once` (stream and file, sync and async), and concurrent path-save and Combine tests (6 attempts each, one invalid call among them).

Checks run: new and related tests net10.0 60/60 and net48 64/64 (begin, timestamp and signing-rejection filters); full `jaytwo.Ergonomics.Pdf.Tests` net10.0 263 passed, 3 skipped (pre-existing); `make quiet-build` (StyleCop as errors); `make agents-check`, `make task-check`. Not run: net6.0/net8.0, the `jaytwo.Pdf.Tests` suite, the Docker checkpoint, any real timestamp authority.

WORKFLOW-A1 stays partial. Not covered: a successful `Timestamp` as a begin case (External lane, not run), cancellation observed during a builder run (only pre-cancelled tokens), concurrency across `Sign` path terminals and mixed stream and path calls on the builder, and the contract's listed implementation gaps (fail-if-exists, direct output, cleanup reporting). Concurrency tests are bounded probabilistic checks of the atomic claim, not proofs.

# W-130. Move engine tests to jaytwo.Pdf.Tests

## Problem

Reset stage R1 step 2 (`reset-plan.md` section 7). Engine tests live in `test/jaytwo.Ergonomics.Pdf.Tests` and its `netstandard2.0` lane. D-54 splits tests by owning project, and `AGENTS.md` limits `jaytwo.Pdf`'s `InternalsVisibleTo` to its own test, framework-lane, and fuzz assemblies.

## Scope and exclusions

- Establish `test/jaytwo.Pdf.Tests` and its `netstandard2.0` lane; move the parser, writer, forms, metadata, attachments, encryption, revisions, signing, corpus, interop, scale, output-identity, and hardening tests and their fixtures into it.
- Leave `test/jaytwo.Ergonomics.Pdf.Tests` with the boundary test and only public-API tests.
- Restrict `jaytwo.Pdf`'s `InternalsVisibleTo` to the new assemblies and the fuzz assembly.
- Update the `Makefile` test filters and project paths.
- Apply proposal K3 under D-47: the fuzz skill's Layout names `test/jaytwo.Pdf.Tests`.

No test logic changes.

## Acceptance criteria

- The same tests run, now from `jaytwo.Pdf.Tests`; the test count per category is unchanged.
- No Ergonomics test uses `jaytwo.Pdf` internals.

## Evidence required

`make quiet-test LANE=fast` and `make fuzz-smoke`.

# W-33. Add the net48 test target

## Problem

No test ran the library's `netstandard2.0` build on .NET Framework, a G10 gap. The .NET Framework abort-by-dispose path in W-31 was implemented but not tested.

## Why now

The owner approved a `net48` test target under D-19 for both reasons.

## Scope and exclusions

The test project gains a `net48` target that runs against the `netstandard2.0` build. The library targets do not change (D-13). A test that needs a tool or an API the target lacks may be excluded on `net48`, and each exclusion is listed in the report. Add a test of the W-31 abort-by-dispose path.

## Acceptance criteria

The suite builds and runs on `net8.0`, `net6.0`, and `net48`. Any exclusion is listed. The abort-by-dispose test fails when the dispose registration is removed.

## Evidence required

Internally tested.

# W-41. Classic xref subsection bounds

## Problem

Found in W-36. `ParseClassicXref` casts a subsection's start and count from `long` without a range check. QA-B36-02 (Medium): a classic section is built in full before the entry budget applies, alongside the merged map. Under a 256 MiB heap, 2,000,000 entries (a 40 MB file) run out of memory instead of throwing a document exception.

## Why now

It was the limitation W-36 left open, and the next item in the order the board then recorded.

## Scope and exclusions

Range-check classic subsection headers and apply the entry budget while a classic section is read. No parser redesign.

## Acceptance criteria

An out-of-range start or count throws `PdfParseException` before any entries are built. A classic section applies the entry budget while it is read, and stays within 256 MiB or fails with a document exception.

## Evidence required

Not stated in the original entry. Internally tested, with an out-of-process heap-limit probe as the resource evidence.

## Notes

- 2026-10-19: Materialized from B-41 under W-60. Original entry: `agents/state/backlog.md` at `B-41`. Closed entry: `agents/state/backlog.md` at `B-41`.
- A third defect was found and fixed during the work: a hybrid section reached through `/Prev` let its `/XRefStm` override its own table, contrary to ISO 32000-1 7.5.8.4 and `ACCEPTANCE.md`.

## Closeout

Accepted at the internally tested level, with an out-of-process heap-limit probe as the resource evidence.

- Classic subsection headers are range-checked before their rows are read (`start >= 0`, `count >= 0`, `start + count <= 2^31`).
- Classic sections merge straight into the one map under the entry budget, which closes QA-B36-02. Under a 256 MiB heap, a 40 MB section that ran out of memory now ends in a document exception at 150 MiB allocated. Rows are parsed from one reused 18-byte buffer.
- `LoadXref` merges the classic table first, then loads `/XRefStm` without overwriting, then follows `/Prev`, which fixes the hybrid precedence defect.

Eight regression tests, each failing on the unfixed code. 309/309 on Windows `net8.0`, `net6.0`, and `net48`, and on Linux. `ACCEPTANCE.md` names the hybrid `/Prev` case and adds a classic subsection row under Limits; the `README.md` Limits row gains the range. Limitation: duplicate rows within one older classic section now keep the first row. Report: `agents/reports/2026-10-19-B-41.md`. Completed 2026-10-19.

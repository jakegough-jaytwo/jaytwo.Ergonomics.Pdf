# D-60. The R2 workflow contract

## Context

Reset stage R2 builds `jaytwo.Ergonomics.Pdf` workflows (`reset-plan.md` section 8), but `docs/spec/` had no workflow requirements. W-141 put nine design questions to an outside expert who had no access to the code, then checked the answer against the engine. `agents/reference/r2-workflow-proposal.md` holds the full proposal: the review, the API sketch, and the caller-code comparison.

## Decision

Proposed; pending the owner's approval of the proposal's sections 2, 3, and 5.

1. A workflow binds one input through `PdfWorkflow.From` (a `Stream` or an `IPdfSource`) or `FromFile` (a path). It reads nothing until a terminal call, snapshots its arguments, and runs once.
2. Caller-supplied streams and sources are always borrowed. Files the workflow opens from paths are owned for the run only.
3. A run applies every operation through one `PdfDocumentEditor` and saves once. Fills merge, last value wins, into one bulk fill before any flatten. Every other operation replays on the editor in declaration order, so the engine stays the only authority on each rule.
4. Engine exceptions propagate unchanged. Workflow-shape errors use the framework argument and `InvalidOperationException` types and are thrown before the input opens. No destination is written until every operation has been applied.
5. The outputs are a stream (empty, writable, seekable), a path (a temporary sibling, then `File.Move` or `File.Replace` with `Overwrite`), and an explicit `AppendToSource`. Non-seekable destinations are rejected, and an output path equal to the input path is rejected.
6. Signing stays out of the workflow until stage R4. Flatten and rotation on a signed document need `AllowBreakingExistingSignatures()`, which never relaxes certification, FieldMDP, or password permissions.
7. The requirement rows F1 to F16 go into `docs/spec/phase-1.md` section 6.7 with status New.

## Consequences

- W-141 adds the approved rows to the spec and refines the acceptance criteria of W-142 to W-145.
- W-145 implements form export only.
- Remote sources are not advertised as nonblocking until W-138 settles asynchronous inspection.

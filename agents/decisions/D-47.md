# D-47. An approved rule change also updates the files that only restate it

## Context

W-90 and W-97 each stopped after the owner had approved a rule change, because `QUALIFICATION.md` or a skill file restated the superseded rule and needed a separate approval for a conforming edit.

## Decision

When the owner approves a change to a rule or behavior, the work item that makes it also updates `QUALIFICATION.md` and `.agents/skills/` where they only restate the superseded rule, without separate approval. It lists each such edit in its commit message and Notes for the owner's review. Any other change to those files, and any change to `AGENTS.md` or `docs/spec/` text, still needs the owner's approval of the wording.

## Consequences

An implementing item lists the restating files in `allowed_changes`. An edit that adds, widens, or reinterprets a rule in those files is still proposed to the owner.

## Authority

The owner, 2026-10-21, under W-100.

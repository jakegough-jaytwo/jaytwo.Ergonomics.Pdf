# D-51. Windows test tools come from one script; netstandard2.0 is tested on Linux

## Context

A native Windows test run needed about 1.2 GB of tools installed by hand from five sources and ten `JAYTWO_*` variables kept outside the repository. winget and Chocolatey do not provide a `pdfsig` built against NSS or SoftHSM 2, and they install machine-wide at unpinned versions. Cygwin builds depend on `cygwin1.dll`, which an in-process PKCS#11 module cannot use; MSYS2 `ucrt64` packages are native. Poppler is GPL and MuPDF is AGPL, so their binaries are not committed.

No Linux test ran the `netstandard2.0` build: each modern test host loads the library build for its own framework, so only Windows `net48` exercised it. A `netstandard2.0` build on a modern runtime covers that build's compiled code paths and its dependency packages, but not .NET Framework runtime behavior, so it supplements `net48` rather than replacing it.

## Decision

- The Windows test tools are installed by `tools/test-tools/install.ps1` into the git-ignored `.tools/` folder, at pinned versions with SHA-256 checks, without administrator rights. It writes `.tools/test.runsettings`, which test projects load when it exists and no other run settings are set. A new test tool is added to the script and to the `Dockerfile` `base` stage in the same change.
- Python test packages are pinned once, in `tools/test-tools/requirements.txt`, for both the script and the `Dockerfile`.
- Tests start every external tool, Python included, through `ExternalTool.Locate`.
- The test sources also run on `net8.0` against the `netstandard2.0` build, in `test/jaytwo.Ergonomics.Pdf.NetStandard.Tests`, as part of `make unit-test`. `net48` on Windows keeps the full suite.

## Consequences

A fresh Windows clone runs the full suite after one script and no environment setup. The `JAYTWO_*` overrides remain for tools installed elsewhere. Jenkins runs the `netstandard2.0` build. The suite runs on one more framework, which lengthens `make unit-test`. Narrowing `net48` remains open and needs its own decision.

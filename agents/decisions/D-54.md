# D-54. Architectural reset: engine and workflow libraries

## Context

`reset.md` sets the owner's product direction. The owner's reset interview on 2026-10-23 settled the decisions behind it, and `reset-plan.md` records the approved migration. `agents/reference/reset-phase-0-proposal.md` (W-127) listed the protected text that contradicted the reset; the owner approved it on 2026-10-23 and W-128 applied it.

## Decision

- The twelve decisions in `reset-plan.md` section 1: a clean pre-1.0 break; a new, non-packable `jaytwo.Pdf` engine project in this solution; the one-way dependency `jaytwo.Ergonomics.Pdf -> jaytwo.Pdf`; signing moved into the engine as-is and changed only for regressions or migration breakage until after document assembly; a public random-access source abstraction with async reads, cancellation, and explicit ownership, with cloud adapters deferred; a read-only `PdfDocument` whose `Edit()` returns the `PdfDocumentEditor` that owns changes, saves, and signatures; Ergonomics as a deferred, intent-oriented workflow over one editor session, not a mirror of the engine API; the raw object model kept internal; tests split by owning project; the 1.0 NuGet release track suspended; document assembly before further signing work.
- The reset's delivery steps are stages R0 to R5. "Phase 1" and "Phase 2" in `docs/spec/` name scope, not releases.
- The 1.0 release track is suspended. Evidence recorded against the pre-reset project and API is historical input, not evidence for a gate.
- Until stage R4, signing changes only for a regression or migration breakage.

## Consequences

- Supersedes D-38's mapping of Phase 1 to release 1.0 and of Phase 2 to 1.x, and nothing else in D-38.
- D-15 stands but has no release to gate until packaging is decided.
- D-49's bounded cursor windows carry into the `IPdfSource` caching rules; the R1 source item states how.
- `agents/reference/charter-reset-plan.md` (W-61) is historical.
- `reset-plan.md` is a binding source, after `QUALIFICATION.md` and before work items and decisions, until its section 14 completion criteria are met.

## Authority

The owner, 2026-10-23.

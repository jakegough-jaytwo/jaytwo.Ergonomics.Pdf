# D-43. A shipping item marks its spec requirement Exists

## Context

`AGENTS.md` has the item that implements a New or Change requirement set it to Exists in the same commit, but it also lets `docs/spec/` change only with the owner's approval. Every shipped requirement therefore needed a separate approval for a status edit, as W-66 and W-84 showed for R11.

## Decision

The work item that ships a requirement marked New or Change sets its status to Exists in the same commit, together with `ACCEPTANCE.md` and `README.md`, without separate approval. Changing a requirement's text, adding or removing a requirement, or moving one between phases still needs the owner. `QUALIFICATION.md`, `AGENTS.md`, and `.agents/skills/` are unchanged by this decision.

## Consequences

A shipping item lists the phase spec in `allowed_changes` and edits only that requirement's status there. Any other spec edit is still proposed to the owner.

## Authority

The owner, 2026-10-20, under W-85.

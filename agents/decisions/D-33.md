# D-33. Repository-native work items use the W prefix

The owner approved the workflow-review plan on 2026-10-19, with `W-` replacing the proposed `B-` prefix.

- Each work item has one stable file in `agents/work-items/`; status changes never move it.
- Work-item kinds are metadata, not directories or ID namespaces.
- Decisions remain separate durable records in `agents/decisions/`.
- `agents/state/current.md` is the only maintained ordering file. Status views are derived.
- Task-specific evidence stays in the work item. Reusable evidence belongs under `agents/evidence/`.
- V1 provides `make agents-check`, `make agents-status`, and staged `make task-check` validation. Git-hook and history-wide enforcement are deferred until an observed need justifies them.
- Legacy state is archived byte-for-byte. Open B items map to W items with the same number and retain the B ID as an alias. Closed B items stay in the archive unless reopened or annotated.
- Generated tools must write to ignored paths rather than receive standing workflow exceptions.

This decision changes workflow organization only. It does not override the product charter, acceptance contract, or qualification bar.

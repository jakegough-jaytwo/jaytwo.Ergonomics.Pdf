# D-68. Reconcile intended image and security-permission scope

## Context

W-218 established CHARTER.md and SUPPORTED.md as enduring intent documents. Older exclusions in AGENTS.md, README, and the phase specs contradicted image placement and image-to-PDF. The initial reconciliation also proposed a narrower security-permission scope and additional approval gates that the owner did not adopt.

## Decision

- Limited blank-page creation and image placement for image-to-PDF conversion, stamping, and image watermarking are explicit exceptions to the general authoring/layout exclusion. SUPPORTED.md owns capability boundaries; behavior.md describes current support.
- Get/set security permissions remains intended scope. Limiting setters to already-encrypted PDFs with owner authentication is a proposal, not an adopted restriction. Credentials, supported changes, encryption interaction, and output strategy require an operation contract. The commitment itself does not authorize adding encryption, password changes/removal, or a new rewrite strategy; existing exclusions and N5 evaluation remain separately governed.
- Implementation requires an adopted operation contract. Product-scope changes, architectural changes, and new full-document rewrite strategies require owner approval under the charter. This decision creates no blanket owner-approval requirement for every detailed specification or delivery-order choice.
- W-218 preserves 8-bit, non-interlaced RGB/RGBA as the initial PNG implementation boundary. JPEG restrictions and detailed image semantics remain to be specified.

## Consequences

Reconcile the charter, contributor rules, README, and phase exclusions with short cross-references. Preserve current API guarantees and N1/N2 contracts. Intended additions have no implementation claim or newly assigned delivery stage. Other existing constraints remain in force; this is not blanket adoption of unimplemented features or a rewrite strategy.

## Authority

Jake approved revision and adoption on 2026-10-27, explicitly correcting the initial proposal in agents/reference/W-218-scope-reconciliation.md on images, permissions, governance, and PNG scope.

# D-28. Top-level `tools/` directory


Decided 2026-10-19 by the owner. The repository may have a top-level `tools/` directory for CI-visible validators and runners, such as the fuzz runner and the corpus-manifest validator. Fixtures, baselines, and qualification records stay in ordinary repository locations, not in skill folders.

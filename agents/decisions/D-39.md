# D-39. An async compatibility package is approved on netstandard2.0

## Context

Phase 1 (`docs/spec/phase-1.md` W20) makes the signer, timestamp authority, and save operations asynchronous. On `netstandard2.0`, `ValueTask` and `IAsyncDisposable` are not in the framework; they come from `System.Threading.Tasks.Extensions` and `Microsoft.Bcl.AsyncInterfaces`. `AGENTS.md` makes every runtime package other than `System.Memory` an owner decision.

## Decision

The `netstandard2.0` build may reference `Microsoft.Bcl.AsyncInterfaces`, which brings `System.Threading.Tasks.Extensions`, so the public API can use `ValueTask`, `ValueTask<T>`, and `IAsyncDisposable` on every target. The reference is conditioned on `netstandard2.0` only. The `net8.0` and `net10.0` builds keep no runtime package references.

Add the reference in the work item that introduces the first async public API, not before.

## Consequences

The settled runtime dependency set on `netstandard2.0` becomes `System.Memory` plus this package and what it brings. `AGENTS.md` and `README.md` are updated to say so under the charter-update item. As with `System.Memory`, this is settled: do not flag it or cite it to justify another package.

## Authority

The owner, 2026-10-19, under W-61.

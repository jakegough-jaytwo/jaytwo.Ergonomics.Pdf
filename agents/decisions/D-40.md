# D-40. net6.0 stays a target

## Context

D-38 set the 1.0 targets to `netstandard2.0`, `net8.0`, and `net10.0`, dropping `net6.0` and `netstandard2.1`. The reset plan's A4 justified dropping `net6.0` by its end of vendor support. D-13 had earlier said a target is dropped only for a compatibility reason, not because its runtime left support.

## Decision

The library targets `netstandard2.0`, `net6.0`, `net8.0`, and `net10.0`. `net6.0` stays even though it is out of vendor support. `netstandard2.1` is still dropped, as D-38 set. Tests run on `net6.0`, `net8.0`, and `net10.0`, plus `net48` on Windows.

## Consequences

This amends D-38's target list. `docs/spec/phase-1.md` §9 and the reset plan's A4 say the same. As D-13 intended, do not propose removing `net6.0` on support-lifecycle grounds. The `Dockerfile` keeps a `net6.0` runtime alongside the `net8.0` and `net10.0` SDK and runtimes.

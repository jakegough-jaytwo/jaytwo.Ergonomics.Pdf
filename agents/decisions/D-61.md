# D-61. The R3 page-assembly contract

## Context

Reset stage R3 builds new-file page extraction (N1) and concatenation (N2) (`reset-plan.md` section 9), but `docs/spec/phase-2.md` was a draft outline with ten open interview questions. Two outside experts with no access to the code answered the questions over three rounds. `agents/reference/r3-assembly-proposal.md` holds the answers and how each disagreement settled.

## Decision

1. N1 and N2 are adopted. The spec's sections 2, 3, 5, and 6 carry the behavior, and requirements A1 to A15 are New until the work item that ships each one sets it to Exists (D-43). N3 to N5 stay a draft outline for stage R5.
2. The writer copies selected pages by typed per-structure policy, never by reachability. It copies streams raw, writes `/Length` as an indirect object where needed, writes a page tree of at most 64 children per node, and writes a header of 1.5 or later with a classic cross-reference table when it fits and a cross-reference stream when it does not. It writes no object stream.
3. Outlines, tagged structure, page labels, XMP, document attachments, signatures, and catalog actions are omitted. A nonempty `/AF` within the bounded inspection scope, a nonempty `/OCProperties`, and dynamic XFA are refused. The structure tree is not traversed for `/AF`, and the spec says so.
4. Links are rebuilt from a whitelist. A link that has `/Next`, `/IsMap true`, `/AA`, an unsupported scheme, or userinfo is omitted whole. A relative URI is resolved against a valid `http` or `https` catalog `/URI /Base`. A link to a repeated page targets its first occurrence within the same input occurrence, and a link to its own page targets its own copy. The option has two states.
5. An encrypted input needs an explicit option, and the output is always unencrypted. The permission rule is: owner bypasses `/P`; for a user, R2 needs bits 4 and 5 and R3 or later needs bits 5 and 11, for every input. It is a conservative product policy, because ISO 32000 defines no bit for building a file from selected pages.
6. Memory follows the imported structure, with explicit budgets and a dedicated resource-limit error. A local `/AP` limit omits its annotation; a global limit or an integrity failure aborts. A failure after output begins leaves an invalid file the caller must discard.
7. The result reports omissions by reason code and count, not by object or page.

## Consequences

- The R3 work items W-161 to W-166 implement A1 to A15 in the order in `agents/state/current.md`. W-164 needs W-154, which separates authentication from permissions.
- A12 sets a header of 1.5 or later for a new file. The 1.7 cap in the Phase 1 incremental-save rule does not apply to a new file; a new file's version comes from the retained features.
- A tagged document loses its tagging, and an association that exists only on a discarded structure element can pass A5 undetected. Callers who need either must use a different tool.

## Authority

The owner, 2026-10-24. The owner approved adopting the converged answers, then forwarded an outside review of the proposal approving the direction and requiring wording corrections to A1, A2, A3, A5, A7, A8, A9, A12, A13, and A15. This decision and the spec reflect those corrections.

# W-190: editable forms in assembly

Research date: 2026-10-26. Product baseline: `3895f5a1e30a3a8ca56d4fc643821227fbb18543`. Single planning editor; no independent reviewer and no fresh-context review claimed. W-188 is complete; its unavailable review attachments remain unavailable. This report establishes current observations and a proposal, not adoption or release qualification.

## Result

Retain occurrence-local editable forms. The measured text, checkbox and choice examples preserve values, field inheritance, page geometry, encoded content, appearances and later edits without binding one occurrence to another. Preserve the current `InputN` naming and page-widget ownership rules. Propose refusal for an unpreservable retained ordinary-form widget instead of successful omission. No product, shipped contract, protected file or queue reprioritization is made here; closeout removes only the completed W-190 entry.

The current appearance omission is a documented limit (phase-2 A9, ACCEPTANCE.md page-assembly section, docs/behavior.md page-assembly section), not a newly discovered violation of those clauses. The charter's preservation direction is target research; it does not supersede A9. Empty signature fields and tag semantics remain W-194 and W-191 respectively.

## Scope of support and refusal

Measured support: nested/separate and merged text fields; two widgets of one field on separate pages; inherited values and page properties; widgets without P; repeated pages and repeated inputs; shared appearance resources; a non-executed resource back-reference; shared checkbox states; simple single-choice options; form-level NeedAppearances; default-font name collisions.

Measured refusal: field Kids cycle, multiply owned terminal field, page widget absent from AcroForm, unresolved DA font, non-font DR, and an action on an unselected widget. The whole field tree is read before selected field pruning; retained widget AP classification follows that pruning. Form-level CO checks are whole-form. Defaults are imported when any widget survives; all default fonts/categories are considered, not only a proven minimum resource closure. Page content is never interpreted.

Source inspection additionally establishes the DA operator whitelist (Tf, g, rg, k, Tc, Tw, Tz, TL, Tr, Ts), fixed field key set, widget-parent depth bound and inherited signature exclusion. This is code evidence, not an executed result for every operator or field key. Default DA font copying is distinct from self-contained existing AP resources.

Proposal classifications: Preserve ordinary selected forms in the measured subset; Exclude unselected widgets/empty ancestors by selection; Refuse unsupported or ambiguous retained field semantics; keep bounded inspection and immutable-resource sharing. Signature fields, active behavior, XFA/rights, tags and explicit derivatives retain their separately scheduled decisions. Do not infer an arbitrary JavaScript scan, sanitization, viewer fidelity for every font, or preservation of unknown field dictionary entries from these probes.

## Compatibility, effort and remaining evidence

Business use: collect several editable business forms in one packet while retaining later fill/export capability. Matching names across customers must remain independent; repeated copies inside one input occurrence intentionally remain one field. A caller needing different answers on two copies supplies two occurrences. Page selection deliberately removes unselected widgets and their empty ancestors, not their source file.

No useful responsibility is deleted by retaining forms. Parser/copier mappings, field pruning, occurrence parents, font remapping, ownership, bounded inspection, fill/appearance code and permissions remain necessary. Replacing widget omission with refusal simplifies the success contract but adds admission/error/regression work. Do not count that work, or future tag/unsigned-signature preservation, as deletion savings. Estimate: 1–2 engineering days for namespace/ownership regression and wording hardening; 1–3 days for ordinary-widget refusal plus failure/publication checks; 0.5–2 days to assess harmless AP dictionary extensions such as LastModified. Basis: localized Import/Supported paths and the compact probes here; these are planning ranges, not measured implementation time. W-192/W-197 may share admission changes, so do not add their savings or tests twice.

Migration: retaining InputN spelling needs no caller migration. A future refusal replaces successful but incomplete output on the affected cases; the host must surface the typed unsupported reason and obtain a supported source/prepared derivative. No auto-flatten or silent loss fallback is proposed. Encryption consent and credentials remain governed by existing rules. No corpus-wide added refusal count, preparation success rate or customer demand was measured here; E190-9 proves concrete loss only. Do not offer a derivative/recovery API before its own decision.

Limits: no independent reviewer; unavailable review attachments; no radio, multiselect choice, rich text, non-WinAnsi, arbitrary embedded-font, duplicate/Unicode-name, hostile-depth boundary, state-specific R/D appearance, signed/locked, XFA, accessibility or cross-platform equivalence claim. These gaps block claims about those variants, not the measured subset or this contract proposal. W-191/W-194/W-197/W-203 own their separate semantic questions. Proposed future implementation must promote each fixed defect's minimal fixture into a permanent regression test; this research has not changed or fixed runtime behavior. No framework matrix, fuzz, Docker checkpoint or release qualification was required or run.

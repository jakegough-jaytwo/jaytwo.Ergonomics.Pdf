# W-193 Gate 2 proposal

Draft, 2026-10-26. Research only. R193 identifiers below are local proposal labels, not adopted requirements. Approval must cover exact wording and implementation tickets. Replace the relevant A9/A10 and basic-annotation contract paragraphs only in the approved implementation transaction; coordinate actions with W-192, admission with W-197 and field defaults/tags with W-194. Current omission behavior remains shipped.

## Exact proposed wording

**R193-1 - Supported annotation semantics.** Assembly preserves selected-page Text, Square, Circle, Line, Polygon, PolyLine, Ink, Highlight, Underline, Squiggly and StrikeOut annotations within the typed key subset below. It also preserves static Stamp and Caret annotations with an existing supported normal appearance, and plain FreeText annotations with an existing supported normal appearance and preservable default text resources. Popup annotations are supported only as the companion of a supported markup annotation. Links use the separate navigation/action contract; widgets and signature widgets use the separate field/signature contract. Unsupported subtypes or meaningful variants on retained pages refuse assembly before destination writing. Unsupported Stamp, Caret and FreeText appearances are not replaced by generic icons, generated text, flattened page content or inert rectangles. An annotation without the required existing appearance for these three added subtypes refuses. Existing supported subtypes may retain their standard reader-generated appearance when AP is absent; assembly does not generate it.

**R193-2 - Typed keys.** Preserve and type-check applicable common entries Type, Subtype, Rect, Contents, NM, M, F, Border, BS, C, AP and AS. Preserve applicable markup entries T, Subj, CreationDate and CA. Preserve Text Name/Open, Square/Circle IC/RD, Line L/LE/IC, Polygon Vertices/LE/IC, PolyLine Vertices/LE/IC, Ink InkList/BS, and text-markup QuadPoints. Preserve Stamp Name and Caret RD/Sy. Preserve FreeText Contents/DA/Q, BS/RD, and IT when absent or FreeText; DA is restricted to the existing supported text-state/device-color grammar and its font reference must resolve to retained, occurrence-local default resources. Copy/remap that font binding using the field-default resource machinery; a missing or unsupported binding refuses even when AP currently renders. No FreeText callouts, typewriter intent, rich text, styles or cloudy borders are supported by this slice. Explicit non-null RC, DS, ExData, Measure, BE, unhandled intents, line captions/leader-line semantics, or other standard meaningful entries outside this typed subset refuse. Preserve Text State/StateModel for standard Marked and Review states with a valid IRT chain and author; refuse unsupported state models or invalid combinations. Popup, Parent, IRT and RT follow R193-3. Source P is validated and rebuilt, never copied. Annotation A/AA outside the supported Link/Widget contracts refuse; Popup may not have either or AP. Unsupported optional-content bindings refuse. Associated-file and accessibility rules remain governed by their approved admission/preservation contracts; this proposal authorizes no attachment or tag stripping. Unknown annotation extension keys refuse until explicitly classified as supported or inert in the contract. A missing or PDF-null optional entry is treated as absent, except where the governing action contract explicitly distinguishes presence. Malformed required values refuse; they are never repaired by guessing.

**R193-3 - Relationships and ownership.** Build a bounded typed inventory of the selected source page's Annots before creating output annotations. Every retained annotation has one unambiguous source page owner: its P, when present, must agree with its Annots membership. A reference listed under different source pages or duplicated within the same Annots array refuses. Each output page instance receives distinct annotation objects and P values naming that output page. The identity key includes input occurrence, selected page instance and source annotation identity; reusing the same document or repeating a page never joins annotation ownership or relationships. Immutable appearance/resource mappings may be shared within an occurrence, independently of annotation ownership.

Markup Popup references must resolve to a Popup on that same source page. Parent, when present on that Popup, must be an indirect reference to that markup owner; an absent Parent is emitted as the unambiguous owner established by Popup. A Popup must have exactly one such markup owner and must be listed in the page's Annots. Preserve its Rect, applicable flags and Open value and emit reciprocal Popup/Parent references to the copies on the same output page instance. The ordinary reciprocal pair is allowed; orphaned, multiply owned, non-Popup, mismatched or cross-page pairs refuse. Copy no separate Popup AP or actions.

IRT must be an indirect reference to a supported markup annotation on the same source page and in that page's Annots. RT is absent (meaning R), R or Group, and is meaningful only with IRT. Preserve reply chains and groups, including their applicable text/state attributes, without changing a Group to a reply or a reply to a standalone comment. Cyclic IRT chains, a Group target that is itself subordinate (has IRT), missing targets, invalid RT values and conflicting ownership refuse. Remap each relationship to the corresponding annotation on the same output page instance. The first-selected-copy navigation rule does not apply to annotation ownership or replies. Cross-page IRT is malformed even when both pages are selected; selecting or excluding its target page does not legalize it.

**R193-4 - Selection and closure.** A wholly excluded source page's annotations and their page-local relationships are outside inspection, except for the already approved whole-input checks. Assembly never imports an excluded page merely to satisfy an annotation relationship. Every retained relationship must be valid within its selected source page; there is no successful target-dropping fallback. Inspect the entire retained AP normal/rollover/down state graph and required resource closure structurally, preserve AS selection, BBox, Matrix and encoded stream bytes, and reject unsupported semantics instead of dropping the annotation. Resource sharing and legitimate indirect resource cycles terminate through visited identity mappings, without recursive expansion. A shared AP is not a reason to share annotation objects. Page content streams remain opaque; appearance programs are copied, not executed or decoded to discover dependencies. Typed resource dictionaries bound what is imported; this is not unrestricted reachable-object cloning or a guarantee that an arbitrary content program is semantically valid.

**R193-5 - Bounds and failures.** Retain the existing per-appearance limits of 4,096 inspected objects, depth 32 and 8 MiB of encoded stream bytes plus structural data. Apply the operation-wide mapped-object, structural-memory, traversal and output-page budgets to inventories, relationship edges, output copies and copied resources. Count work before allocation; visited sets bound repeated graph walks. Preflight relationships and retained appearances for every occurrence before destination writing. Unsupported semantics use PdfAssemblyNotSupportedException, malformed source relationships/required values use PdfParseException, and exhausted local or global limits use PdfResourceLimitException. Source-integrity failures retain their specific errors. Diagnostics use W-197's occurrence/category frame without document contents or host details. A refused operation returns no result and leaves destination bytes unchanged before writing. Existing later source/destination I/O guarantees are unchanged. Preflight does not prove physical retry safety after output begins.

**R193-6 - Results.** Supported annotations and relationships are preserved; they are not counted as omissions. UnsupportedAnnotation and UnsupportedAppearance successful omissions cease for the scopes replaced by this contract. Other explicitly approved new-document exclusions and external-link Drop behavior retain their fixed-cardinality counts. No best-effort mode, per-subtype switch, generic strip operation or automatic derivative is introduced.

## Decision and evidence limits

Recommend the bounded typed subset over a larger general annotation editor. Retaining markup semantics adds responsibility; strict refusal replaces omission policy but does not remove traversal, resource closure, ownership, or security gates. AP-only static copying is insufficient evidence for FreeText regeneration. The no-AP refusal is a compatibility cost, not a statement that standard icon Stamp/Caret or viewer-generated FreeText are invalid. Extending those cases deserves a separately approved preservation slice with viewer evidence. See findings.md for measured baseline, counterfactual counts and customer-evidence gaps.

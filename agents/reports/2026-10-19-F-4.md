# F-4: list-box `/I` and generated appearance

## Task

Reproduce the claim that list-box fills leave stale selection indices and generate an incomplete appearance, then separate correctness from the supported appearance subset.

## Verified facts

The regression fixture starts with `/V (A)` and `/I [0]`, then fills the list box with `B`.

- On the unfixed source, the incremental appendix wrote `/V (B)` but retained `/I [0]`. The focused negative control failed on that contradiction.
- `SetChoice` now removes `/I` before it writes the replacement `/V`.
- The generated appearance draws `(B) Tj`; it does not draw the unselected `A` and `C` options or a selection highlight.
- The fixed focused test passed, followed by 34/34 `AcroFormTests` on each of `net8.0`, `net6.0`, and `net48`.

## Disposition

The stale `/I` state was a correctness defect and is fixed. Drawing only the selected display values is the existing deliberately small list-box appearance subset, not an unapproved expansion of appearance policy. `README.md` and `ACCEPTANCE.md` now state both behaviors.

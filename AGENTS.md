# Repo Instructions

## Product charter

Stream-native PDF operations. See `README.md` and `ACCEPTANCE.md`.

The supported operations are AcroForm fill, AcroForm geometry, incremental PKCS#11 and RFC 3161 sealing, document info and XMP metadata, and embedded-file attachments. Text and image stamping are out of scope. There is no fluent API, renderer, or general PDF framework.

The runtime dependency set is closed and settled: `System.Memory` on `netstandard2.0`, so public methods can take `ReadOnlySpan<byte>`. The owner accepted it. It is not a finding, a gap, or a precedent, so do not flag it, propose removing it, or cite it to justify another package. Any other runtime package is an owner decision. The parser, CMS encoder, and PDF encryption stay in this library. Tests may use external tools. `ForeignPdfTests` and `SigningInteropTests` require qpdf (`JAYTWO_QPDF` or `PATH`) and Python with pyHanko and pypdf. `AppearanceRenderTests` requires Poppler (`JAYTWO_POPPLER` or `pdftotext` on `PATH`). `SigningInteropTests` also requires SoftHSM 2 (`JAYTWO_PKCS11` pointing at `softhsm2-x64.dll` on Windows or `libsofthsm2.so` on Linux, with `softhsm2-util` in the sibling `bin` directory or on `PATH`). `OpenSslTimestampTests` requires OpenSSL 3 (`JAYTWO_OPENSSL` or `openssl` on `PATH`) as a local RFC 3161 authority and token verifier. Those tests fail when a tool is missing. Those tools are not runtime dependencies.

Large-file behavior is part of the design. Memory follows the working set of the operation. Do not buffer a PDF because a streaming decoder is theoretically possible. The 32 MiB and 64 MiB caps are decompression limits. The 8 MiB signature appendix stays until a real revision needs more.

- Public API is `PdfDocument`, `PdfPage`, `PdfRect`, and the document exceptions in namespace `jaytwo.Ergonomics.Pdf`. AcroForm, metadata, attachments, and signatures live in those child namespaces. The parser, serializer, and incremental engine stay `internal` in `jaytwo.Ergonomics.Pdf.Internal`. Open a readable seekable `Stream`. Do not add an API that takes or returns a `byte[]` of the whole PDF. Offsets are `long`.
- Mutations are incremental classic-xref appends. `SaveIncremental` and `Sign` keep the original bytes as a prefix. Same-stream saves append. Cross-stream saves copy with a 1 MiB buffer into an empty destination, then append.
- Read PDF 1.0 through PDF 1.7. An incremental save keeps the original header. Read classic xref (CRLF, LF, SP LF, and SP CR), xref streams with Flate and PNG predictors, hybrid `/XRefStm`, and object streams. Decode `LZWDecode`, `FlateDecode`, `RunLengthDecode`, `ASCIIHexDecode`, and `ASCII85Decode` when a stream's bytes are required, including the abbreviations `LZW`, `Fl`, `RL`, `AHx`, and `A85`. Write classic xref only. Do not allocate an array of `/Size`.
- Do not decode page content streams. Do not add rendering, text extraction, merge/split/rotate, rewrite-in-place, encryption, XFA, JavaScript, annotation editing, redaction, signature validation, PAdES-LTV, or ECDSA.
- Password-based standard security opens with the password passed to `Open`. Revision 2 is 40-bit RC4. Revision 3 is RC4 at 40 to 128 bits. Revision 4 is AES-128 or RC4, chosen by the crypt filter. Revision 5 and revision 6 are AES-256. Decrypt strings and streams on read. Encrypt them on write with that same cipher. Keep `/Encrypt` and `/ID` on the new trailer. Leave signature dictionaries plaintext. Decode a cross-reference stream before resolving `/Encrypt`. An encrypted xref stream is rejected. Refuse public-key encryption. A null password tries the empty user password, which opens a restrictions-only file. A user password honors the permission bits; the owner password does not. `PdfDocument.Permissions` reports those user-access bits. An unencrypted document allows every operation. Revision 2 uses print, modify, copy, and annotate; the later operations follow those four.
- WinAnsi text and choice values get a Helvetica appearance, using Adobe Helvetica advances. A check box with an on-state selects it. A check box with none gets a generated `Yes`/`Off` appearance. A single radio widget with no on-state gets an appearance named for the export value. Comb, rich text, and non-WinAnsi values set `/NeedAppearances` and must not be signed until a consumer has generated appearances. Password and signature fields throw `PdfFieldValueException` and do not dirty the document.
- DocMDP `P` 1 blocks mutation and signing. `P` 2 and `P` 3 allow form fill and signing. Metadata and attachments stay blocked for every certification level. A certification that does not resolve is treated as `P` 1. FieldMDP `All`, `Include`, and `Exclude` apply to fills. Reads stay available. Incremental saves keep existing signature bytes as a prefix.
- PKCS#11 is `IPdfExternalSigner` implemented by the host. `SignHash` receives a raw SHA-256 and must match `RSA.SignHash(hash, SHA256, Pkcs1)`. Do not P/Invoke PKCS#11 from this library. `AdditionalCertificates` carries intermediates and roots. `CmsDetachedSignatureProvider` can take an `ITimestampAuthority` and store the RFC 3161 token as a CMS unsigned attribute over the signature value. `DocTimeStampSignatureProvider` remains a separate document-timestamp revision. `FieldName` reuses an empty signature field.
- No runtime NuGet dependencies beyond the settled set above. Tests may reference packages. StyleCop warnings are errors. XML docs on the public API. One top-level type per file. File-scoped namespaces. Private fields use an underscore prefix.
- The type is not thread-safe. `Dispose` does not save.

## CI

- Jenkins builds the `builder` stage of the `Dockerfile` on Ubuntu and runs `make unit-test` there on net8.0 and net6.0. net48 tests run on Windows only. Before you commit a checkpoint, run `make docker-builder docker-test`. It reproduces the Jenkins run locally and must pass.
- The Linux image installs every tool the tests require. A change that adds a test needing a new external tool also adds that tool to the `base` stage of the `Dockerfile`.
- Tests find tools through `ExternalTool.Locate` and `ExternalTool.Executable`. Do not hard-code `.exe` names, `where.exe`, or absolute Windows paths. On Unix, `Environment.SetEnvironmentVariable` does not change the native environment that an in-process native library reads.

## Code style

- Match the sibling repos (`jaytwo.Ergonomics.Images`, `jaytwo.Ergonomics.S3`, `jaytwo.AdoTools`, `jaytwo.Ergonomics.Logging`): `src/` and `test/`, shared `Directory.Build.props`, xUnit, Jenkins `nugetProject.build`.
- Implementation types stay `internal`. `InternalsVisibleTo` the test assembly.
- Prefer fixing member order. `SA1201`, `SA1202`, and `SA1204` are suppressed with a file pragma only where the parser, serializer, decoder, object model, and engine interleave static helpers with the operations they serve.
